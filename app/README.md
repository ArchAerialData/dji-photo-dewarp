# DJI Photo Dewarp

Internal Windows desktop tool for batch correction of DJI JPEGs using each
photo's embedded calibration. This directory is an installable Python package.

Double-click `Dewarp.cmd` in the repository root for setup and launch. See
`../.github/README.md` for installation and `../docs/user-guide.md` for usage.
ExifTool is a separate executable installed by `../scripts/Setup.ps1`.
